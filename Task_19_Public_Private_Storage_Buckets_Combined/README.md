# Task 19 — Public & Private Supabase Storage Buckets

This combined React + Node.js + Express + Supabase project demonstrates two access models:

- **Public bucket:** permanent public URL.
- **Private bucket:** temporary signed URL generated by the trusted backend.

## Setup

```powershell
npm install
Copy-Item .env.example .env
code .env
```

Set your real `SUPABASE_URL` and backend `SUPABASE_SECRET_KEY`.

Run this in Supabase SQL Editor:

```text
supabase/task_19_setup.sql
```

Then:

```powershell
npm run dev
```

Frontend: `http://localhost:5173`  
Backend health: `http://localhost:5000/api/v1/health/storage`

## Test

Upload one file to **Public** and click its access button. It should open using a permanent public URL.

Upload another file to **Private** and click its access button. The backend should create a temporary signed URL.

## GitHub safety

```powershell
git check-ignore -v .env
git grep --cached -n -E "sb_secret_[A-Za-z0-9_-]{10,}"
```
