# QuizMaster Pro — Interactive Quiz Assignment

A responsive, animated multiple-choice quiz application built with HTML5, CSS3, JavaScript, and Bootstrap 5.

## Features
- Eight randomized questions selected from a larger question bank; answer choices are randomized too.
- Multi-colored segmented progress bar.
- Two-minute countdown timer with an urgent-state animation; quiz auto-submits when time runs out.
- Immediate correct/incorrect answer highlighting with explanations.
- Dark/light mode toggle.
- Results dashboard with score, correct/incorrect counts, time used, and answer review.
- Downloadable A4 PDF performance report.
- Responsive layout for desktop, tablet, and mobile.
- Polished transitions, hover states, motion effects, accessible labels, and reduced-motion support.
- No build step or package installation required.

## Run it
1. Extract the ZIP file.
2. Open `index.html` in Chrome, Edge, or Firefox.
3. Internet is needed for Bootstrap, Google Fonts, and the jsPDF CDN used for PDF download.
4. For best results, open the folder in VS Code and use the Live Server extension.

## How to test
1. Select an answer and check the green/red feedback.
2. Continue through all eight questions.
3. Toggle dark/light mode at any point.
4. Wait for the timer to reach zero to test auto-submit, or finish normally.
5. Download the PDF from the results screen.
6. Select “Try another round” to start with a fresh randomized question and option order.
