# Task 02: Express Middleware & Error Handling

## Description
A professional Express.js backend task demonstrating middleware architecture,
request logging, and centralized error handling.

## Features
- Express server setup
- Custom request logger middleware
- JSON middleware
- API route handling
- Global error handling middleware
- Structured API response

## Installation

npm install

## Run

npm start

## API Endpoint

GET http://localhost:5001/api/profile
