# NexaTrade — Trading Dashboard UI

Portfolio-level full-stack trading dashboard built with React, Vite, Node.js, Express and Supabase-ready persistence.

> Demo/educational interface only. It does not connect to a broker and does not execute real trades.

## Features
- Premium responsive dark trading dashboard
- Live simulated price movement
- Watchlist
- Portfolio KPI cards
- Custom SVG candlestick-style chart
- Buy/Sell ticket
- Recent orders
- Express API
- Supabase-ready orders table
- Automatic in-memory fallback when Supabase is not configured

## Run
From the project root:

```bash
npm install
npm run dev
```

Open: http://localhost:5173

Backend: http://localhost:5000

## Supabase setup (optional)
Create an `orders` table:

```sql
create table if not exists public.orders (
  id bigint generated by default as identity primary key,
  symbol text not null,
  side text not null check (side in ('Buy','Sell')),
  qty numeric not null check (qty > 0),
  price numeric not null,
  status text default 'Filled',
  created_at timestamptz default now()
);
```

Copy `server/.env.example` to `server/.env` and add:

```env
SUPABASE_URL=your_url
SUPABASE_SERVICE_ROLE_KEY=your_service_role_key
```

The service-role key must stay on the server only.
